		--------------------------
		******	 structure   *****
		--------------------------

*  The structure must define by the name "struct" then you declare
   the structure_name then define the variable.

*  The structure start with the "{ "  (open brase), end with the "}"
   (end brase).

*  After the end brase we have to put the ; (semicolon),
   then we have to create the object in function main.
   ex:
      struct csc
      {
	int age;
	int num;
      }
      main()
      {
	struct struct_name obj1,obj2,...;
      }

*  (or)
   After the end brase create the object_name then put semicolon.
   ex:
      struct csc
      {
	int num;
	int age;
      }obj1,obj2...;
      main()
      {
	scanf("%d%d",obj1.num,obj2.age);
      }
